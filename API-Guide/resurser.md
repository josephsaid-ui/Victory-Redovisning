## 📖 Böcker

### Nybörjare

#### 1. **"RESTful Web APIs" av Leonard Richardson, Mike Amundsen, Sam Ruby**
- **Nivå:** Nybörjare → Intermediate
- **Fokus:** REST-principer, HTTP, hypermedia
- **Språk:** Engelska
- **Kommentar:** Den bästa boken för att förstå REST från grunden
- **ISBN:** 978-1449358068
- **Pris:** ~300-400 kr

#### 2. **"APIs for Dummies" av John Paul Mueller**
- **Nivå:** Absolute nybörjare
- **Fokus:** Grundläggande API-koncept utan teknisk jargong
- **Språk:** Engelska
- **Kommentar:** Perfekt för icke-tekniska läsare
- **ISBN:** 978-1119568612

---

### Intermediate

#### 3. **"Designing Web APIs" av Brenda Jin, Saurabh Sahni, Amir Shevat**
- **Nivå:** Intermediate
- **Fokus:** API-design, best practices, användarupplevelse
- **Språk:** Engelska
- **Kommentar:** Från designers på Pinterest, Slack, Google
- **Gratis online:** https://www.oreilly.com/library/view/designing-web-apis/9781492026914/

#### 4. **"Build APIs You Won't Hate" av Phil Sturgeon**
- **Nivå:** Intermediate → Advanced
- **Fokus:** Praktisk API-design, versioner, dokumentation
- **Språk:** Engelska
- **Kommentar:** Konkret och actionable advice
- **Webbplats:** https://apisyouwonthate.com/

#### 5. **"Web API Design: The Missing Link" av Google Cloud**
- **Nivå:** Intermediate
- **Fokus:** REST-design best practices
- **Språk:** Engelska
- **Kommentar:** Gratis e-bok från Google
- **Gratis:** https://cloud.google.com/apis/design

---

### Avancerat

#### 6. **"Microservices Patterns" av Chris Richardson**
- **Nivå:** Advanced
- **Fokus:** Mikroservices-arkitektur, API Gateway, CQRS
- **Språk:** Engelska
- **Kommentar:** Deep dive i distribuerade system
- **ISBN:** 978-1617294549

#### 7. **"GraphQL in Action" av Samer Buna**
- **Nivå:** Intermediate → Advanced
- **Fokus:** GraphQL från grunden till produktion
- **Språk:** Engelska
- **ISBN:** 978-1617295683

#### 8. **"Production-Ready Microservices" av Susan J. Fowler**
- **Nivå:** Advanced

### API-testning

#### 1. **Postman**
- **Typ:** GUI för API-testning
- **Pris:** Gratis (Pro från ~200 kr/mån)
- **Plattform:** Windows, Mac, Linux, Web
- **Features:**
  - Request builder
  - Collections
  - Environment variables
  - Automated testing
  - Mock servers
  - Team collaboration
- **Länk:** https://www.postman.com/
- **Rekommendation:** ⭐⭐⭐⭐⭐ Must-have

#### 2. **Insomnia**
- **Typ:** GUI för API-testning (alternativ till Postman)
- **Pris:** Gratis (Teams från ~150 kr/mån)

  - Minimalistiskt gränssnitt
