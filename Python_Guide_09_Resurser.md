# 🐍 Resurser och vidare läsning

En kurerad lista över de bästa resurserna för att fortsätta din Python-resa.

---

## 📚 Böcker

### För nybörjare

**1. "Automate the Boring Stuff with Python" av Al Sweigart**
- ⭐ Gratis online: https://automatetheboringstuff.com/
- 📝 Praktisk approach, perfekt för nybörjare
- 🎯 Fokus på automation och verkliga problem
- 🇸🇪 Lär dig genom att bygga användbara verktyg

**2. "Python Crash Course" av Eric Matthes**
- 📖 ~500 sidor
- 📝 Hands-on approach med projekt
- 🎯 Från grunder till spel och webb-apps
- ⭐ Mycket välskriven för nybörjare

**3. "Think Python" av Allen B. Downey**
- ⭐ Gratis online: https://greenteapress.com/wp/think-python-2e/
- 📝 Fokus på problemlösning och tänkande
- 🎯 Computer science-perspektiv
- 💡 Bra för att förstå grunderna djupt

### För mellanliggande

**4. "Fluent Python" av Luciano Ramalho**
- 📖 ~800 sidor
- 📝 Djupdykning i Python's features
- 🎯 Bli riktigt bra på Python
- ⭐ Must-read för seriösa Python-utvecklare

**5. "Effective Python: 90 Specific Ways to Write Better Python" av Brett Slatkin**
- 📖 ~350 sidor
- 📝 Best practices och idiomatisk Python
- 🎯 90 konkreta tips
- 💡 Perfekt för att gå från bra till excellent

### För avancerade

**6. "Python Cookbook" av David Beazley & Brian K. Jones**
- 📖 ~700 sidor
- 📝 Recept för vanliga (och ovanliga) problem
- 🎯 Referensbok för erfarna utvecklare
- ⭐ Lösningar på verkliga problem

**7. "Architecture Patterns with Python" av Harry Percival & Bob Gregory**
- 📖 ~300 sidor
- 📝 Design patterns och arkitektur
- 🎯 Bygga stora, underhållbara system
- ⭐ Gratis online: https://www.cosmicpython.com/

### Specialiserade ämnen

**8. "Python for Data Analysis" av Wes McKinney**
- 📊 Data science med pandas, numpy
- 👤 Skriven av skaparen av pandas
- 🎯 Must-have för data science

**9. "Deep Learning with Python" av François Chollet**
- 🤖 Machine learning med TensorFlow/Keras
- 👤 Skriven av skaparen av Keras
- 🎯 Bästa boken för ML med Python

## 🎯 Rekommenderad läsväg

### Nybörjare (0-6 månader)

1. **Bok**: "Automate the Boring Stuff" (gratis online)
2. **Kurs**: freeCodeCamp eller Codecademy
3. **YouTube**: Corey Schafer's Python Tutorials
4. **Övning**: Codewars eller Exercism
5. **Community**: r/learnpython

### Mellanliggande (6-18 månader)

1. **Bok**: "Fluent Python" eller "Effective Python"
2. **Kurs**: Real Python (betald men värt det)
3. **YouTube**: ArjanCodes för clean code
4. **Övning**: LeetCode eller HackerRank
5. **Community**: Python Discord, Stack Overflow

### Avancerad (18+ månader)

1. **Bok**: "Python Cookbook", specialiserade böcker
2. **Resurser**: PEPs, Python source code
3. **YouTube**: mCoding, konferens-talks
4. **Övning**: Open source contributions
5. **Community**: Bidra till projekten, mentorskap
